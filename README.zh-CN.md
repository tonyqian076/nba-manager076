# NBA Manager 使用手册

## 单人模式

可以。别人 clone 或下载这个文件夹后，直接双击 `index.html` 就能开始玩单人模式。

左侧栏可以用 `Language / 语言` 下拉框切换英文或中文界面。

步骤：

1. 打开 `index.html`
2. 选择 `One Player`
3. 选择你要控制的球队
4. 点击 `Start League`
5. 在左侧菜单管理阵容、交易、选秀、自由市场和赛季推进

单人模式不需要安装任何东西。

## 多人模式

多人模式不能只双击 `index.html`，因为不同电脑需要通过同一个服务器同步房间数据。

房主电脑步骤：

1. 确认电脑已经安装 Node.js
2. 在项目文件夹里打开终端
3. 运行：

```bash
npm start
```

4. 房主打开：

```text
http://localhost:3000
```

其他玩家步骤：

1. 和房主连接同一个 Wi-Fi
2. 在浏览器打开房主电脑的局域网地址，例如：

```text
http://房主IP地址:3000
```

3. 选择 `Multiplayer Room`
4. 输入同一个 room key
5. 每个人选择一个还没有被占用的球队

## 游戏流程

- 开始前先选择单人或多人模式
- 每个玩家只能控制一支球队
- 常规赛按阶段推进，每次会让所有球队打到下一个比赛窗口
- 阵容冻结后可以交易、调整首发和轮换
- 赛季结束后进入季后赛、选秀和休赛期
- 10 个赛季后按冠军数量排名，冠军相同再比较亚军次数等

## 文件说明

- `index.html`：游戏入口
- `app.js`：游戏逻辑
- `styles.css`：界面样式
- `data/playerPool.js`：球员池和球队初始名单
- `server.js`：多人模式服务器
- `package.json`：多人模式启动命令
